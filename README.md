---

## 🚀 How to Run Task 4 Platform

### 1. Backend (FastAPI)
```bash
cd task4/platform/backend
pip install -r requirements.txt
python main.py
```

### 2. Frontend (Next.js)
```bash
cd task4/platform/frontend
npm install
npm run dev
```
Visit `http://localhost:3000` to view the platform.
